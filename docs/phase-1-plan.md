# Phase 1 Plan

## Objective

Create a clean, testable, minimal playable DomiNox prototype: draw 7 dominoes, place them on a 6x6 grid, score with `Count x Mult`, compare to quota 80, and show readable feedback.

## Implemented Systems

- Unity project and GitHub repository setup.
- Clean `_Project` folder structure.
- Domino definitions, instances, and double-six factory.
- Domino bag with draw, discard, shuffle, and remaining count.
- Hand state with max size 7.
- Logical 6x6 grid with placement validation.
- Basic pattern detector.
- Score calculator with detailed breakdown.
- Prototype run and level state.
- Minimal main menu and game screen UI.

## Voluntarily Excluded

- Shop, DomiNex effects, consumables, boss rules, complete floor progression, save data, collection, daily challenge, final art, advanced animations, audio, and domino connection rules.

## Recommended Phase 2

Introduce a small extensible modifier/effect pipeline for future DomiNex, boss rules, and consumables before adding large content sets.
